# Veer
CS Senior Design Project

## 1. Overview

Veer is a voice-first Android navigation app. The driver speaks requests such as adding a food stop or avoiding rain, and Veer turns them into routing constraints, proposes a new route, and switches only after the driver says "okay." See [Project_Description.md](Project_Description.md).
